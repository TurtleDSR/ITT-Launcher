This is the It Takes Two launcher app.

Using the exe no Java installation is necessary. If you run the jar directly you will need Java 11+.
Currently only supports the Steam build of the game, I will possibly (unlikely) add EA support in the future. (Console is off the table)

If you have any issues running message me on discord @TurtleDSR
